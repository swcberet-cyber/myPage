# Blackberet

교육사업 회사 Blackberet의 반응형 단일 페이지 홈페이지입니다.

- 회사명: Blackberet
- 업종: 교육사업
- 대표자: 박경훈
- 연락처: 010-2561-3735

`index.html`을 브라우저에서 열면 사용할 수 있습니다. 회사소개와 교육 문의 영역으로 이동할 수 있으며, 연락처를 누르면 지원 기기에서 전화 앱으로 연결됩니다.

별도 설치나 빌드 없이 실행되는 HTML/CSS 페이지입니다. 외부 폰트나 이미지 서비스에 의존하지 않습니다.

## 교육자료

상단 **교육자료** 메뉴에서 `data/알기 쉬운 안드로이드 앱 기초_본문4차.pdf`의 8개 장 요약을 볼 수 있습니다. 장별 목차로 이동하거나 각 요약을 접고 펼칠 수 있으며, 원문 링크로 해당 PDF 페이지를 열 수 있습니다. PDF 페이지 이동은 브라우저 PDF 뷰어 지원 여부에 따라 다를 수 있습니다.

원문: 박경훈·주동현·김영준, 라임하우스, 2025. 과학기술정보통신부 및 정보통신기획평가원이 지원한 SW중심대학사업(2023-0-00076)의 결과물입니다. 요약은 업로드된 교재를 기준으로 작성했습니다.
