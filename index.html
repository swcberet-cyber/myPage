01 / ABOUT BLACKBERET

가능성의 시작에는
언제나 배움이 있습니다.

Blackberet은 교육사업을 통해 배움의 의미와 가치를 전하고자 합니다. 새로운 시작을 준비하는 순간, 교육에 관한 이야기를 함께 나누겠습니다.

02 / LEARNING LIBRARY

알기 쉬운 안드로이드 앱 기초

처음 앱을 만드는 학습자를 위한 Java 기반 안드로이드 입문서입니다. 개발 환경 준비에서 화면 구성과 사용자 입력을 거쳐, 공공데이터를 활용하는 앱으로 이어지는 8개 장의 핵심 내용을 정리했습니다.

01

개발 환경 설정

제1장 · 원문 9–26쪽

안드로이드 앱의 역할과 주요 구성요소를 살펴보고, 개발과 실행에 필요한 도구를 준비하는 단계입니다.

  • Activity, Service, Content Provider, Broadcast Receiver의 역할을 구분합니다.
  • Android Studio와 SDK를 설정하고 AVD를 만들어 앱을 실행할 환경을 갖춥니다.

핵심 키워드: Android Studio · SDK · AVD

02

앱 구조와 인터페이스

제2장 · 원문 27–52쪽

프로젝트 파일의 역할을 파악하고 Java 코드와 XML 레이아웃을 연결해 앱 화면을 구성합니다.

  • AndroidManifest.xml과 Gradle 설정이 프로젝트에서 맡는 역할을 이해합니다.
  • View와 Widget을 배치하고 LinearLayout, RelativeLayout으로 화면 구성을 연습합니다.

핵심 키워드: Manifest · Gradle · XML

03

이벤트 처리

제3장 · 원문 53–74쪽

사용자의 버튼 클릭에 반응하도록 이벤트를 연결하고, 상황에 맞는 처리 방식을 비교합니다.

  • 익명 클래스, 리스너 참조 객체, Activity의 인터페이스 구현 방식을 살펴봅니다.
  • XML의 onClick 속성 방식까지 비교하며 코드 구성과 유지보수 관점에서 선택합니다.

핵심 키워드: OnClickListener · 익명 클래스

04

메뉴와 대화상자

제4장 · 원문 75–124쪽

사용자에게 기능을 선택하게 하거나 확인과 입력을 요청하는 인터페이스를 구성합니다.

  • 옵션 메뉴, 컨텍스트 메뉴, 팝업 메뉴의 차이와 사용 맥락을 익힙니다.
  • AlertDialog와 날짜·시간 선택 대화상자를 사용하고 커스텀 레이아웃을 연결합니다.

핵심 키워드: Menu · AlertDialog · Picker

05

애니메이션

제5장 · 원문 125–154쪽

화면 요소에 움직임을 더하는 여러 기법을 비교하고 XML과 Java 코드로 동작을 구현합니다.

  • 트윈 애니메이션과 프레임 애니메이션을 구분하고 Interpolator의 역할을 살펴봅니다.
  • Property Animation과 ObjectAnimator를 활용해 속성 변화와 복합 동작을 표현합니다.

핵심 키워드: View Animation · ObjectAnimator

06

액티비티와 인텐트

제6장 · 원문 155–180쪽

화면의 생성과 전환 과정을 이해하고, 다른 화면이나 외부 앱에 작업과 데이터를 전달합니다.

  • Activity 생명주기, 상태 보존, 백스택과 태스크의 동작을 이해합니다.
  • 명시적·암시적 Intent를 비교하고 Parcelable 전달 및 웹·전화·지도·공유·카메라 연동을 실습합니다.

핵심 키워드: Activity · Intent · Parcelable

07

어댑터 뷰

제7장 · 원문 181–216쪽

데이터와 화면 항목 사이를 연결하는 Adapter의 역할을 이해하고 목록 형태의 UI를 만듭니다.

  • ArrayAdapter, SimpleAdapter, CursorAdapter, BaseAdapter의 용도를 구분합니다.
  • ListView의 항목 표시와 클릭 이벤트를 구현하고 ViewHolder를 통한 뷰 재사용을 익힙니다.

핵심 키워드: Adapter · ListView · ViewHolder

제7장 PDF 원문 보기 ↗
08

공공데이터 앱 개발

제8장 · 원문 217–252쪽

앞에서 익힌 화면·이벤트·목록 구성을 결합해 구조동물 조회 API를 활용하는 Java 앱을 만드는 종합 실습입니다.

  • 공공데이터 활용 신청과 인증키 준비 후 요청 매개변수와 응답 구조를 확인합니다.
  • Retrofit과 Gson으로 응답을 객체에 연결하고 목록에 표시하며 네트워크 오류와 화면 상태 처리를 학습합니다.

핵심 키워드: Open API · Retrofit · Gson
